# Responsive Website

This project is a responsive website based on the given UI Design using HTML, CSS, Bootstrap 5, and Javascript. The objective is to ensure the website works efficiently on all types of devices.

# Features
Responsive Layout: 
- this website is desktop-first approach as the content relies more on the visual design.
- bootstrap media queries are used to adjust the layout to smaller screens like tablet and mobile.

Javascript: 
- project uses JS functionalities such as form validation and animation.

Modal Implementaion: 
- it includes bootstrap modal to provide pop-up registration form for easier user interaction.

# Setup
Prerequisites:
- any modern web browser.
- any code editor. Eg., VS Code.

How to run the website:
- step 1 - clone the repository from github
- step 2 - directly open the index.html in your web browser or use live server in a code editor.

Customization:
- to change style, edit the style.css file or inline css using bootstrap.
- to customize Javascript, modify the script.js file.
